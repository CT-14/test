# ADR 0008: Magic-link sign-in with signed session cookies

Status: accepted, 2026-11-04

## Decision

Passwordless email magic links (single use, 15-minute expiry, stored hashed).
Sessions are `HttpOnly`, `Secure`, `SameSite=Lax` cookies signed with
`APP_SECRET`. Authorization is per account: every query is scoped by
`account_id` taken from the session, never from the request.

## Consequences

No password storage or reset flows. Depends on email delivery (ADR 0005).
